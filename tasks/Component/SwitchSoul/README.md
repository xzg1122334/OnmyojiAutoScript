# 切换预设御魂

按分组、队伍序号切换和按名称切换，都先检查御魂更换确认弹窗：识别固定文字“即将更换式神”，点击黄色“确定”，再连续两次截图确认弹窗已经关闭。式神名称不参与匹配。

目标预设已经装备时游戏不会弹出确认框。成功点击目标队伍两次，第二次点击后等待 1.5 秒，再连续两次截图未见弹窗，就按已装备继续；识别失败或点击间隔阻止的点击不计数。任一次出现过确认框，就必须点击确认并等到关闭，不能走已装备分支。

过程超过 30 秒仍未完成时抛出 `GameStuckError`，调用任务不能继续记录切换成功或进入战斗。只看见黄色按钮而未识别弹窗内容时继续等待，避免点击其他确认框。

默认式神录和 `costume_shikigami_12` 的旧确认图片已替换为当前游戏按钮；其余式神录保留各自的按钮素材。素材仅包含识别文字或按钮，不包含游戏昵称。
