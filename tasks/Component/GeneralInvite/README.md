# 战后邀请队友

`I_GI_SURE` 对应“是否邀请队友继续进行战斗”的黄色确定按钮，`I_I_NO_DEFAULT` 和 `I_I_DEFAULT` 对应圆形的默认邀请勾选框。旧素材已替换，并允许小幅位置偏移。

`check_and_invite()` 保留原有默认邀请设置：启用时先勾选，再点击确定；已经勾选时直接确认；失败弹窗没有勾选框时也可以确认。八岐大蛇队长的奖励处理先调用该流程，弹窗存在时不继续随机点击奖励页。

默认邀请的已勾选状态是棕色圆圈与浅色勾选，不使用其他弹窗的蓝色勾选素材。勾选状态最多等待五秒；仍未识别时记录警告并继续确认本次邀请，避免一直停留在此处。

仅按钮和勾选状态进入 Git；参考弹窗和报告放在已忽略的 `dev_tools/local/invite-confirm`。
