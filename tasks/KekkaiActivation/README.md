# 结界放卡

放卡最低星级和最高星级均包含边界，默认只放 3～5 星资源卡。
卡片须同时满足类型、星级和最低收益要求；在当前页的合格卡中优先选择收益较高的卡。
找不到合格卡时继续翻页，并沿用原有的重试和太鼓/斗鱼切换规则。

太鼓、斗鱼都按星级范围过滤。星级图片使用完整星星行，同时保留橙色与灰色图标，
避免相似卡片图案造成星级误判；同一行有多种匹配时合并并比较置信度，六星模板也参与校验以排除六星卡。
星级不明确或无法对应收益文字的卡片会被跳过。
进入任务时若已有选中但尚未激活的卡，由于其星级未经过本轮验证，脚本会跳过激活；请先卸下，再运行任务。
已经激活且正在使用的卡继续运行到结束。

激活时出现“寄养位置一设为公开，寄养位置二设为私有”的弹窗，会在核对弹窗文字后
点击右侧黄色“确定”；弹窗存在时不会继续点击底层的“激活”按钮。

本地验证（不连接模拟器、不放卡）：

```powershell
.\toolkit\python.exe -B dev_tools/verify_kekkai_cards.py
.\toolkit\python.exe -B dev_tools/verify_activation_confirm.py <弹窗截图路径> [--offset X Y]
```

还可传入 `--panels <截图目录>`，用真实截图执行图片匹配、收益 OCR 和选卡检查。
目录需包含 `panels.json`：每项填写 `file`、局部图在原画面的 `offset: [x, y]`、
`type`（太鼓或斗鱼）、`allowed_stars` 和 `selected_yield`；诊断材料放在已忽略的 `dev_tools/local` 中。
