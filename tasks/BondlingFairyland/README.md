# 契灵挑战弹窗

鸣契石计数使用右上角的数量区域，避开上下边缘对数字识别的干扰。识别失败返回的 `(0, 0, 0)` 不能作为耗尽依据：最多重新截图读取三次，连续两次读到有效的零数量才退出；始终无法确认时报告识别失败。离线验证使用 `toolkit/python.exe -B dev_tools/verify_bondling_stone.py <1280x720 鸣契弹窗截图>`，不操作模拟器。

千咒式盘、万象式盘等数量达到上限时，先处理“无法再次获取，是否继续”提示：未勾选时点击“当天不再提醒”，已勾选时直接点击“确定”。复用通用邀请组件中的当前棕色勾选框和黄色按钮，但只在式盘上限文字匹配后使用。

单人挑战和组队求援均优先处理此弹窗，点击冷却期间不点底层按钮。单人挑战最多点击三次，然后等待进入战斗；启动等待最多 30 秒。无法启动时报告弹窗或容量待检查，不能仅凭点击失败推断契灵数量达到 500，也不能按正常完成退出。

离线验证工具为 `dev_tools/verify_bondling_confirm.py`；它记录预期点击，不连接模拟器。局部截图、报告放在已忽略的 `dev_tools/local/bondling-confirm`，原文件备份位于 `config/backup`。
